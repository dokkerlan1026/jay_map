# 花蓮店家地圖 - Google 試算表共同編輯與每日開關排程系統

本專案支援：
1. **Google 試算表（Excel 線上版）多人共同編輯**：每一筆店家與地址都有專屬的**核取方塊（Checkbox）**，勾選/取消立即標記「顯示」或「關閉」。
2. **每日獨立紀錄**：每天自動以「當天日期」記錄排程狀態，歷史紀錄永久留存。
3. **隔天快速範本載入**：新的一天開始時，可一鍵**「載入全開啟（全部顯示）」**，或**「複製昨天 / 指定日期的開關設定」**。
4. **雙向連動地圖 Web App**：無論在試算表打勾，還是在手機/電腦地圖網頁勾選，兩邊即時同步！

## 🚀 完整建置與部署教學（約 3 分鐘完成）

### 第一步：建立 Google 試算表並綁定 Apps Script
1. 開啟 [Google 雲端硬碟](https://drive.google.com/)，點選 **「＋ 新增」 > 「Google 試算表」**。
2. 將試算表命名為：`花蓮店家每日排程管理表`。
3. 點選試算表上方功能表的 **「擴充功能」 > 「Apps Script」**。

---

### 第二步：貼上程式碼
1. 在 Apps Script 編輯器左側，點選 `程式碼.gs`：
   - 清空所有預設內容。
   - 開啟本機的 [`gas/Code.gs`](file:///c:/Users/lan/Desktop/map/gas/Code.gs)，**全選複製並貼上**。
2. 在左側「檔案」旁邊點擊 **「＋」** 號 ➜ 選擇 **「HTML」**：
   - 檔名輸入 **`Index`**（請務必輸入 `Index`，不需輸入 `.html`）。
   - 開啟本機的 [`gas/Index.html`](file:///c:/Users/lan/Desktop/map/gas/Index.html)，**全選複製並貼上**。
3. 按下鍵盤 `Ctrl + S` 儲存專案。

---

### 第三步：一鍵初始化 500 筆店家資料表
1. 回到剛才的 **Google 試算表** 視窗，按下 `F5` 重新整理頁面。
2. 重新整理後，上方功能表最右側會出現一個全新專屬選單：**`🗺️ 店家地圖與每日排程`**。
3. 點擊：**`🗺️ 店家地圖與每日排程` > `🟢 1. 建立/初始化 500 筆店家工作表`**。
   - （首次執行時，Google 會彈出授權視窗，點選「審查權限」> 選擇您的 Google 帳戶 > 點「進階」>「前往專案(安全)」>「允許」）。
4. 完成後，試算表會自動建立【**當日店家清單**】：
   - **B 欄為原生核取方塊（Checkbox）**：打勾代表開啟顯示，取消打勾代表關閉隱藏。
   - 包含店名、地址、分組分類（東區綠色 / 西區紅色 / 非488橙色）、經緯度。

---

### 第四步：部署為網頁應用程式（Web App）
1. 回到 Apps Script 頁面，點選右上角藍色的 **「部署」 > 「新增部署作業」**。
2. 左上角齒輪 ⚙️ 選擇 **「網頁應用程式」**（Web app）。
3. 填寫設定：
   - **說明**：花蓮店家每日排程地圖
   - **執行身分**：選擇 **「我」**（Me）
   - **誰可以存取**：選擇 **「所有人」**（Anyone）
4. 點選 **「部署」**。
5. 複製生成的 **網頁應用程式網址**，即可將地圖分享給外勤或團隊使用！

## 👥 如何共同編輯與每日作業流程

### 1. 多人線上共同編輯
- 點選 Google 試算表右上角的 **「共用」** 按鈕，將檢視／編輯權限分享給同事的 Google 帳號（或設為「知道連結的使用者皆可編輯」）。
- 大家可以在試算表的 **B 欄（顯示開關）直接打勾或取消打勾**，所有人畫面即時連動！

### 2. 隔天早上的操作（二選一）
到了新的一天（例如隔天上班要排定全新行程）：
- **想要全新全開**：
  點選試算表選單：`🗺️ 店家地圖與每日排程` ➜ **`☀️ 2. 【隔天操作】載入全開啟`**
  （或直接在地圖網頁頂部點選 `☀️ 載入全開啟` 按鈕）
  👉 **B 欄的 500 家店會一鍵全部打勾開啟，日期自動更新為今日！**
- **想要延續昨天（或指定日期）的設定**：
  點選試算表選單：`🗺️ 店家地圖與每日排程` ➜ **`📋 3. 【複製前日】載入昨天的開關狀態`**
  （或點 `📅 4. 載入指定日期的開關狀態` 輸入特定日期）
  👉 **系統會自動抓取歷史紀錄，將當天關閉的店家狀態無縫複製到今天！**

### 3. 外勤手機地圖連動
- 外勤人員在外面使用手機開啟 Web App 網址：
  - 勾選或取消左側的任何一家店，地圖圖釘即時切換。
  - 同時會自動同步寫回 Google 試算表該行的 Checkbox，內勤在辦公室也能即時看到最新勾選狀況！
