# 花蓮店家地圖 - Google Apps Script (GAS) 部署指南

本專案提供使用 **Google Apps Script** 打造的 Web App 完整原始碼，外觀風格高度還原 **Google 我的地圖（Google My Maps）**，並支援**左側清單獨立勾選／取消顯示個別店家**與三大群組批次控制。

---

## 📁 檔案清單

- [`Code.gs`](file:///c:/Users/lan/Desktop/map/gas/Code.gs)：Apps Script 後端主程式（包含 `doGet` 進入點、內建 500 筆花蓮店家完整座標與 Google 試算表自動連動工具）。
- [`Index.html`](file:///c:/Users/lan/Desktop/map/gas/Index.html)：前端網頁樣板（包含 Google 我的地圖經典紅色工具列、Leaflet 互動地圖、水滴型圖釘、左側三組圖層樹狀折疊清單、個別店家 Checkbox 連動控制）。

---

## 🚀 部署步驟（3 分鐘完成）

### 步驟 1：建立 Apps Script 專案
1. 開啟瀏覽器進入 [Google Apps Script 官方首頁](https://script.google.com/)。
2. 點擊左上角的 **「＋ 新專案」**（New Project）。
3. 將專案標題命名為例如：`jay的花蓮店家地圖`。

> 💡 **進階技巧（直接綁定 Google 試算表）**：
> 您也可以先在 Google 雲端硬碟建立一個全新的「Google 試算表」，接著在試算表上方選單點選 **「擴充功能」 > 「Apps Script」**，這樣做之後還可以將 500 筆資料直接自動同步在試算表上管理！

---

### 步驟 2：貼上程式碼
1. 在左側的「檔案」清單中，點選預設的 `程式碼.gs`（或 `Code.gs`）：
   - 清空原有內容，開啟本機的 [`Code.gs`](file:///c:/Users/lan/Desktop/map/gas/Code.gs)，將全部內容**複製並貼上**。
2. 在左側「檔案」旁邊點擊 **「＋」** 號 ➜ 選擇 **「HTML」**：
   - 輸入檔案名稱：`Index`（檔名請務必輸入 `Index`，不需輸入 `.html`）。
   - 開啟本機的 [`Index.html`](file:///c:/Users/lan/Desktop/map/gas/Index.html)，將全部內容**複製並貼上**。
3. 按下鍵盤上的 `Ctrl + S`（或工具列的磁碟圖示「儲存專案」）。

---

### 步驟 3：部署為網頁應用程式（Web App）
1. 點擊右上角藍色的 **「部署」**（Deploy）按鈕 ➜ 選擇 **「新增部署作業」**（New deployment）。
2. 在彈出視窗左上角齒輪圖示 ⚙️ 選擇種類為 **「網頁應用程式」**（Web app）。
3. 填寫部署設定：
   - **說明**：例如「花蓮店家地圖 v1.0」
   - **執行身分**：選擇 **「我」**（Me）
   - **誰可以存取**：選擇 **「所有人」**（Anyone）或「任何擁有 Google 帳戶的使用者」
4. 點擊右下角 **「部署」**（Deploy）。
5. 首次部署時，Google 可能會要求授權，點選「核准存取權」即可。
6. 完成後，畫面會顯示一組 **「網頁應用程式網址」**（格式為 `https://script.google.com/macros/s/.../exec`）。
   - 👉 **點擊該網址，即可在電腦或手機瀏覽器中直接使用完整的地圖網頁！**

## 🌟 功能亮點

1. **左側清單獨立勾選（核心功能）**：
   - 每一間店家（共 500 筆）前面皆有獨立的 **核取方塊（Checkbox）**。
   - 勾選即時在地圖上顯示圖釘，取消勾選即時隱藏。
2. **三大分區快速控制**：
   - 🟢 **主要名單 - 東區（194筆）**：界線以東（林森路+德安一街以東），以綠色水滴圖釘標記。
   - 🔴 **主要名單 - 西區（194筆）**：界線以西，以紅色水滴圖釘標記。
   - 🟠 **非 488 名單（112筆）**：以亮橙色水滴圖釘標記。
   - 每個大群組上方皆有**「全選 / 取消全選」**按鈕與折疊展開功能。
3. **頂部快捷按鈕**：
   - 「全部顯示」、「全部隱藏」、「僅看東區」、「僅看西區」、「僅看非488」。
4. **搜尋與導航**：
   - 支援店名、路名、地址即時過濾。
   - 點擊左側任一店家自動平滑飛至該地圖點並展開 Popup。
   - 點擊 Popup 內的「Google 導航 ↗」按鈕，一鍵開啟 Google 地圖進行手機或電腦即時導航。
